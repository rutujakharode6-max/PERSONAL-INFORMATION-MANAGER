# ✨ Personal Information Manager ✨

A beautiful terminal-based Personal Information Manager with modern styling, emoji icons, and rounded box aesthetics!

## How to Run

1. Open your terminal or command prompt.
2. Run the script using Python:
   ```bash
   python personal_info.py
   ```
3. Alternatively, you can run it with the provided test inputs:
   ```bash
   python personal_info.py < test_inputs.txt
   ```
