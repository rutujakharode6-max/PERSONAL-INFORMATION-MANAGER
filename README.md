# ✨ Personal Information Manager ✨

A beautiful, modern, gradient-themed Personal Information Manager built completely in Python using Flask.

## Features
- **Modern Aesthetic**: Beautiful gradients and glassmorphism card design.
- **Emoji Support**: Rich emoji integration.
- **Python Only**: Powered by Flask (`app.py`), rendering inline styled HTML.

## How to run
1. Install Flask:
   ```bash
   pip install flask
   ```
2. Run the application:
   ```bash
   python app.py
   ```
3. Open `http://127.0.0.1:5000` in your web browser.
